# C++ ATM Banking System

A console-based ATM banking system developed in C++ to demonstrate object-oriented programming, STL, database persistence, unit testing, and CMake.

## Features

- Account creation and management
- PIN authentication
- Check account balance
- Deposit money
- Withdraw money
- Transfer money between accounts
- Transaction history
- Account lookup by minimum balance
- Savings account with interest
- SQLite database persistence
- Exception handling
- Unit testing with GoogleTest
- CMake build system

## Technologies

- C++
- STL
- SQLite
- GoogleTest
- CMake
- MinGW

## C++ Concepts

- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- `virtual` and `override`
- `unique_ptr`
- `vector`
- `unordered_map`
- Lambda expressions
- STL algorithms
- Exception handling
- File and database I/O
